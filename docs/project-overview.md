# Project Overview

This project is a simple quiz application inspired by "Who Wants to Be a Millionaire".

The goal is not to build a complex product, but to apply DevOps practices such as:
- Continuous Integration (GitHub Actions)
- Containerisation (Docker)
- Version Control (GitHub)

## Current status
- Initial Python quiz structure created
- Docker container working locally
- CI pipeline configured
- Project structure organised
- Local UI page added for presentation/demo purposes

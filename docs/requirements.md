## Functional Requirements

- The system asks the user quiz questions
- Questions are selected randomly
- Each question has 4 possible answers, with only 1 correct
- The user starts with €10
- Each correct answer doubles the current amount
- After each question, the user can choose to continue or stop
- If the user answers incorrectly, they lose all the money
- The user can restart the game after losing

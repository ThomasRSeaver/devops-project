# Testing Strategy

Because the original QA role is no longer assigned to one person, the team is currently using a shared testing approach.

## Current Testing Types
- Functional testing for quiz logic
- UI testing for local preview pages
- Smoke testing through GitHub Actions and Docker

## Shared Responsibility
- Developer: checks application flow and logic
- IT Operations: checks Docker and CI pipeline behaviour
- Business Analyst: documents testing scope, expected behaviour, and visible issues
